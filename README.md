# Mohammad Reza Heravi — Portfolio

Bilingual German / English personal portfolio.

Built with HTML, CSS and JavaScript. No build step or external dependencies.

## Local preview

Run `python3 -m http.server 8000` and open http://localhost:8000.

## Editing

- `index.html`: layout and styles
- `content.js`: German and English content
- `assets/portrait.jpg`: profile photo

Published with GitHub Pages from the main branch root.
